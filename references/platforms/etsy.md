# Etsy profile

## Scope and listing model

- Etsy is for qualifying handmade, vintage, and craft-supply listings. Confirm that the item and production arrangement qualify under current Etsy policies before preparing a launch package.
- Require target language and product type. Category and attribute choices are listing-editor driven.
- Keep the actual item, personalization option, production partner, and AI disclosure facts explicit. Never write a mockup as though it were a photograph of a finished custom item.

## Content and images

- Use a descriptive, buyer-readable title and accurate tags/attributes; avoid turning the title into a keyword dump.
- Main photo: original photograph of the exact item. Listing image policy has limited exceptions for personalized/customized products and production-partner mockups, especially for additional images; check the specific exception before using a mockup as the primary image.
- Etsy image guidance snapshot: first image should be at least 635 px on each side to avoid reduced search display; 2000 px or larger is recommended; sRGB is recommended. File guidance lists JPG/JPEG, PNG, GIF, SVG and HEIC; transparent PNG and animated GIF are not supported as expected storefront imagery.
- Generated promotional composites are not automatically the same as an AI-created item. If the **item itself** was created using AI, disclose that according to Etsy's current creativity standards. For listing photos, follow the exact-product photo rule and the limited mockup exceptions.
- Suggested image plan: exact product, alternate angle, scale, detail, personalization example, packaging, and context. These are recommended story beats, not a required count.

## Preflight

1. Confirm the item qualifies for Etsy and record how it was made, including any production partner or AI involvement.
2. Ensure the primary photo represents the actual item and follows the current exception rules if using a mockup.
3. Check file, image count, variation and listing-editor requirements for the current listing.
4. Confirm materials, dimensions, personalization, processing/production facts, and required disclosures.

Sources and review dates are recorded in [`platform-rules.json`](platform-rules.json).
